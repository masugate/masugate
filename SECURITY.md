# Security policy

Do not include credentials, private keys, access tokens, customer data, or
other confidential information in a report or repository artifact.

Report a vulnerability privately at
[masugate.governance@gmail.com](mailto:masugate.governance@gmail.com). Use
the repository's private vulnerability-reporting route when it is enabled. Do
not publish an exploit, a credential, or a reproduction involving a live
account in an issue or discussion.

The current connector boundary treats connector code as trusted for its assigned
secret handles and destinations. That is a limit of the implementation boundary,
not a guarantee that arbitrary connector code is safe.

Version: `0.1.0` (research preview). Next: [Governance](GOVERNANCE.md).
