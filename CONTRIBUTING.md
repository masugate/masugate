# Contributing

Contributions are welcome through a focused
[issue](https://github.com/masugate/masugate/issues) and pull request. Before
opening a substantial pull request, discuss its scope in an issue or with a
maintainer. Never submit credentials, private data, generated archives, or
third-party material whose redistribution terms are unclear.

Make focused changes, preserve the declared policy and protocol boundaries,
update the relevant tests and reader documentation, and identify any changed
claim, premise, exclusion, or evidence gate for maintainer review. Do not
introduce compatibility aliases or private paths into publication-safe material.

For a local source checkout, follow the [source-checkout bootstrap](docs/testing.md#source-checkout-bootstrap)
before running tests. The in-tree connector SDK must be installed before the
root editable package; this is a development arrangement, not an instruction
to add a local-path dependency to a built distribution.

Version: `0.1.1` (research preview). Next: [Security policy](SECURITY.md).
