# Governance

Maintainers administer repository access, review changes, and decide whether a
release gate is satisfied. Repository settings are the source of truth for
active maintainers and protected-branch controls.

Changes affecting protocols, claims, exclusions, package identities, security,
or release automation require maintainer review. Release publication also
requires the configured review and protection controls. Conduct and security
reports follow the adjacent [code of conduct](CODE_OF_CONDUCT.md) and
[security policy](SECURITY.md).

Version: `0.1.1` (research preview). Next: [Code of conduct](CODE_OF_CONDUCT.md).
